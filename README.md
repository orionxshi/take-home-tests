# Take-Home Tests

A collection of take-home coding tests from various companies, organized by role type and company.

## Structure

Tests are organized in the following hierarchy:

```
<role-type>/
  <company-name>/
    README.md        # Instructions or notes about the test
    <test files>
```

## Role Types

- [software-engineer](./software-engineer/) — Software engineering take-home tests
- [data-science](./data-science/) — Data science / ML take-home tests
- [frontend](./frontend/) — Frontend / UI take-home tests
- [backend](./backend/) — Backend / API take-home tests

## Contributing

When adding a new test, place it under the appropriate role directory and company subdirectory. Include a `README.md` in the company folder describing the test prompt and any relevant notes.
